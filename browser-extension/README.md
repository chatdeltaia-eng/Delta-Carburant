# Extension interne Delta Carburant

Installation unique dans Chrome/Edge :

1. Ouvrir `chrome://extensions` (ou `edge://extensions`).
2. Activer **Mode développeur**.
3. Cliquer **Charger l’extension non empaquetée** et sélectionner ce dossier.

Ensuite, utiliser **Reconnecter Total automatiquement** dans Delta Carburant. Le portail
Total s'ouvre. Si la session a expiré, l'utilisateur saisit seulement son login Total.
Dès que Total ouvre votre espace, l'extension renouvelle la connexion et lance
l'extraction. Aucun mot de passe Total n'est enregistré par l'extension.
